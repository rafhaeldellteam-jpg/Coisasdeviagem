# Coisas de Viagem

Checklist de mala para praia e hotel com piscina. PWA estático (HTML/CSS/JS puro), salva o progresso no próprio aparelho (localStorage) e funciona offline.

- Progresso geral e por categoria
- Adicionar e remover itens
- Esconder itens já separados / ver só o que falta
- "Desmarcar tudo" para a próxima viagem

Deploy: Vercel (site estático, sem build).

Desenvolvido por Phael Tech Support.
